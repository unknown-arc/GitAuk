# Code of Conduct

## Our Commitment

GitAuk is intended to be an open and respectful open-source project.

Participants should communicate professionally and focus criticism on ideas, code, documentation, and technical decisions rather than individuals.

## Expected Behavior

- Be respectful and constructive.
- Welcome different levels of experience.
- Explain technical disagreements with evidence and reasoning.
- Give useful feedback.
- Respect project maintainers and contributors.
- Avoid harassment, discrimination, or personal attacks.

## Unacceptable Behavior

- Harassment or threats.
- Personal attacks.
- Discriminatory or hateful conduct.
- Deliberate disruption of project discussions.
- Publishing private information without permission.

## Enforcement

Project maintainers may take appropriate action when this code of conduct is violated.

Serious incidents should be reported privately to the maintainers.

## Status

The final reporting contact and enforcement procedure will be defined before the first public release.
