# Architecture Decision Records

Architecture Decision Records (ADRs) document important technical decisions and their reasoning.

## Naming

```text
NNNN-short-title.md
```

Example:

```text
0001-service-boundaries.md
0002-gitauk-metadata-format.md
0003-analysis-result-versioning.md
```

## When to Create an ADR

Create an ADR when a decision:

- affects multiple services,
- changes a public contract,
- introduces a major dependency,
- changes data ownership,
- affects security,
- affects scalability,
- is difficult to reverse.
